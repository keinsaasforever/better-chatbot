# Morphik PDF Viewer Implementation Guide

## Overview

This guide documents how to implement PDF.js to properly display PDF files returned by the Morphik MCP server. Morphik returns both image previews and actual PDF files, but browsers cannot render PDF files inside `<img>` tags, requiring a dedicated PDF viewer solution.

## Problem Statement

### Current Issue

When Morphik processes PDFs (especially with ColPali), it can return two types of URLs:

1. **PDF Page Previews as Images** ✅ Works
   - Format: `https://morphik-storage.s3.amazonaws.com/.../page-1-preview.jpg`
   - These are JPG/PNG images of PDF pages generated by ColPali
   - Can be displayed in `<img>` tags without issues

2. **Actual PDF Files** ❌ Doesn't Work
   - Format: `https://morphik-storage.s3.amazonaws.com/ingest_uploads/.../document.pdf`
   - These are the original uploaded PDF files
   - Cannot be displayed in `<img>` tags - causes error: "Failed to load image: [filename].pdf"

### Root Cause

Browsers cannot render PDF files inside HTML `<img>` elements. When the `ImageViewer` component receives a PDF URL, the browser fails to load it as an image, resulting in broken previews.

### Current Error

```
[ImageViewer] Failed to load image: adidas-runtastic-identity-guidance.pdf
[ImageViewer] URL prefix: /api/proxy-image-morphik?url=https%3A%2F%2Fmorphik-storage.s3.amazonaws.com%2Fingest_uploads%2F82b08...
```

## Current Architecture

### Existing Files

#### `src/lib/utils/morphik-parser.ts`

Parses Morphik MCP responses and converts them to `MediaResource` format:

- Extracts `[IMAGE_URL]`, `[TITLE]`, `[SCORE]`, `[DOC_URL]`, `[PREVIEW]` tags
- Detects if source is a PDF based on title
- Proxies S3 URLs through backend
- **Current limitation**: Doesn't distinguish between PDF page images and actual PDF files

#### `src/components/media/image-viewer.tsx`

Displays media resources including images with PDF metadata:

- Renders images with tooltip, modal view, and metadata badges
- Shows "PDF" badge when `metadata.isPdf` is true
- Falls back to `media.url` when `media.thumbnail` is undefined
- **Current limitation**: Always uses `<img>` tag, which fails for actual PDF files

```typescript

```

#### `src/app/api/proxy-image-morphik/route.ts`

Proxies external S3 URLs to bypass CORS restrictions:

- Validates allowed domains (morphik-storage.s3.amazonaws.com)
- Fetches pre-signed URLs from S3
- Returns with appropriate Content-Type and CORS headers
- **Current limitation**: Works for images, but serves PDF files which can't be rendered in `<img>`

Defines the `MediaResource` type:

## PDF.js Integration Solution

### Installation

```bash
pnpm install pdfjs-dist --save
```

Reference: [PDF.js NPM Package](https://www.npmjs.com/package/pdfjs-dist)

### Implementation Approach

The solution involves three main changes:

1. **Improve PDF detection** in `morphik-parser.ts` to identify actual PDF files vs. PDF page images
2. **Create new `PdfViewer` component** using PDF.js for rendering PDF files
3. **Update `ImageViewer`** to conditionally render `PdfViewer` for PDF files

## Step-by-Step Implementation

### Step 1: Update Morphik Parser

**File**: `src/lib/utils/morphik-parser.ts`

Update the `morphikToMediaResources` function to properly detect PDF files:

```typescript
export function morphikToMediaResources(
  morphikResults: MorphikResult[],
): MediaResource[] {
  const validResults = morphikResults.filter((result) => {
    if (!result.imageUrl) return false;
    
    // For actual PDF files without previews, we need to skip or handle differently
    const urlIsPdf = 
      result.imageUrl.toLowerCase().endsWith(".pdf") ||
      result.imageUrl.includes("/ingest_uploads/");
    
    const hasCompletePreview =
      result.previewData &&
      result.previewData.startsWith("data:image/") &&
      result.previewData.length > 1000;
    
    // Skip PDF files without valid preview thumbnails
    // These will need PDF.js rendering
    if (urlIsPdf && !hasCompletePreview) {
      console.warn(
        `[Morphik Parser] Skipping PDF file without preview: ${result.title || result.imageUrl}`
      );
      return false;
    }
    
    return true;
  });

  console.log(
    `[Morphik Parser] Converting ${validResults.length} results to MediaResources`,
  );

  return validResults.map((result, index) => {
    // Check if the IMAGE_URL itself is a PDF file (not a preview image)
    const urlIsPdf = 
      result.imageUrl.toLowerCase().endsWith(".pdf") ||
      result.imageUrl.includes("/ingest_uploads/");
    
    // Check if the source document is a PDF (based on title)
    const sourceIsPdf = result.title?.toLowerCase().endsWith(".pdf");

    const hasCompletePreview =
      result.previewData &&
      result.previewData.startsWith("data:image/") &&
      result.previewData.length > 1000;

    const needsProxy = result.imageUrl.includes("amazonaws.com");
    const imageUrl = needsProxy
      ? `/api/proxy-image-morphik?url=${encodeURIComponent(result.imageUrl)}`
      : result.imageUrl;

    const mediaResource: MediaResource = {
      // Use "pdf" type if URL is actually a PDF file, otherwise "image"
      type: urlIsPdf ? "pdf" : "image",
      url: imageUrl,
      mimeType: urlIsPdf ? "application/pdf" : "image/png",
      title: result.title || `Result ${index + 1}`,
      description: result.score
        ? `Relevance score: ${result.score.toFixed(2)}`
        : undefined,
      thumbnail: hasCompletePreview ? result.previewData : undefined,
      metadata: {
        score: result.score,
        isPdf: sourceIsPdf,
        fullDocumentUrl: result.docUrl,
        sourceUrl: result.imageUrl,
        showFullDocumentLink: !!result.docUrl,
      },
    };

    console.log(`[Morphik Parser] Created MediaResource ${index + 1}:`, {
      type: mediaResource.type,
      proxied: needsProxy,
      hasThumbnail: !!mediaResource.thumbnail,
      urlIsPdf,
      sourceIsPdf,
    });

    return mediaResource;
  }).filter((r): r is MediaResource => r !== null);
}
```

**Key Changes**:

- Check if `IMAGE_URL` is an actual PDF file (`.pdf` extension or `/ingest_uploads/` path)
- Set `type: "pdf"` for actual PDF files
- Set `mimeType: "application/pdf"` for PDF files
- Filter out PDF files without valid previews (since we can't render them as images)
- Log detailed debugging information

### Step 2: Create PDF Viewer Component

**File**: `src/components/media/pdf-viewer.tsx` (new file)

```typescript
"use client";

import { useState, useEffect, useRef } from "react";
import { Loader2, FileText, ExternalLink } from "lucide-react";
import { Button } from "ui/button";
import * as pdfjs from "pdfjs-dist";
import type { PDFDocumentProxy, PDFPageProxy } from "pdfjs-dist";
import { MediaResource } from "@/types/media";
import { cn } from "lib/utils";
import { notify } from "lib/notify";

// Set worker path for PDF.js
// Using CDN for simplicity - alternatively copy worker to public folder
if (typeof window !== "undefined") {
  pdfjs.GlobalWorkerOptions.workerSrc = `//cdnjs.cloudflare.com/ajax/libs/pdf.js/${pdfjs.version}/pdf.worker.min.js`;
}

interface PdfViewerProps {
  media: MediaResource;
  className?: string;
  showTooltip?: boolean;
}

export function PdfViewer({ media, className, showTooltip = true }: PdfViewerProps) {
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState<string | null>(null);
  const [pageCount, setPageCount] = useState<number>(0);
  const canvasRef = useRef<HTMLCanvasElement>(null);
  const pdfDocRef = useRef<PDFDocumentProxy | null>(null);

  useEffect(() => {
    let isMounted = true;

    const loadPdf = async () => {
      try {
        setLoading(true);
        setError(null);

        // Load PDF document
        const loadingTask = pdfjs.getDocument(media.url);
        const pdf = await loadingTask.promise;
        
        if (!isMounted) return;
        
        pdfDocRef.current = pdf;
        setPageCount(pdf.numPages);

        // Render first page as thumbnail
        const page = await pdf.getPage(1);
        
        if (!isMounted || !canvasRef.current) return;

        const canvas = canvasRef.current;
        const context = canvas.getContext("2d");
        
        if (!context) {
          throw new Error("Could not get canvas context");
        }

        // Calculate scale to fit thumbnail size (max 400px height)
        const viewport = page.getViewport({ scale: 1 });
        const scale = Math.min(400 / viewport.height, 300 / viewport.width);
        const scaledViewport = page.getViewport({ scale });

        canvas.height = scaledViewport.height;
        canvas.width = scaledViewport.width;

        // Render page
        await page.render({
          canvasContext: context,
          viewport: scaledViewport,
        }).promise;

        if (isMounted) {
          setLoading(false);
        }
      } catch (err) {
        console.error("[PdfViewer] Error loading PDF:", err);
        if (isMounted) {
          setError(err instanceof Error ? err.message : "Failed to load PDF");
          setLoading(false);
        }
      }
    };

    loadPdf();

    return () => {
      isMounted = false;
      if (pdfDocRef.current) {
        pdfDocRef.current.destroy();
      }
    };
  }, [media.url]);

  const handleClick = () => {
    // Open full PDF in modal or new tab
    if (media.metadata?.fullDocumentUrl) {
      window.open(media.metadata.fullDocumentUrl, "_blank");
    } else {
      // Could implement full-page PDF viewer here
      window.open(media.url, "_blank");
    }
  };

  if (error) {
    return (
      <div
        className={cn(
          "flex items-center justify-center w-full h-36 bg-muted rounded-lg border",
          className,
        )}
      >
        <div className="text-center p-4">
          <FileText className="h-8 w-8 mx-auto mb-2 text-muted-foreground" />
          <p className="text-sm text-muted-foreground">Failed to load PDF</p>
          {media.metadata?.fullDocumentUrl && (
            <Button
              variant="outline"
              size="sm"
              onClick={() => window.open(media.metadata!.fullDocumentUrl, "_blank")}
              className="mt-2"
            >
              <ExternalLink className="h-4 w-4 mr-2" />
              Open PDF
            </Button>
          )}
        </div>
      </div>
    );
  }

  return (
    <div
      onClick={handleClick}
      className={cn(
        "relative block shadow rounded-lg overflow-hidden ring ring-input cursor-pointer hover:ring-primary/50 transition-all duration-200 bg-muted",
        className,
      )}
    >
      {loading && (
        <div className="flex items-center justify-center w-full h-36">
          <Loader2 className="h-8 w-8 animate-spin text-muted-foreground" />
        </div>
      )}
      
      <canvas
        ref={canvasRef}
        className={cn(
          "w-full max-h-[400px] object-contain hover:scale-[1.02] transition-transform duration-300",
          loading && "hidden"
        )}
      />

      {/* PDF badge indicator */}
      <div className="absolute top-2 right-2 bg-background/90 backdrop-blur-sm rounded px-2 py-1 flex items-center gap-1 shadow-sm">
        <FileText className="h-3 w-3 text-muted-foreground" />
        <span className="text-xs font-medium text-muted-foreground">
          PDF {pageCount > 0 && `(${pageCount} pages)`}
        </span>
      </div>

      {/* Relevance score badge */}
      {media.metadata?.score && (
        <div className="absolute top-2 left-2 bg-primary/90 backdrop-blur-sm rounded px-2 py-1 shadow-sm">
          <span className="text-xs font-medium text-primary-foreground">
            {(media.metadata.score as number).toFixed(1)}
          </span>
        </div>
      )}
    </div>
  );
}
```

**Key Features**:

- Uses PDF.js to render first page as thumbnail
- Loads worker from CDN (can be changed to local file)
- Handles loading states with spinner
- Shows error state with fallback to open link
- Displays page count badge
- Maintains same styling as ImageViewer
- Opens full PDF in new tab on click

## Configuration

### Worker Path Options

#### Option 1: CDN (Recommended for Quick Start)

```typescript
pdfjs.GlobalWorkerOptions.workerSrc = 
  `//cdnjs.cloudflare.com/ajax/libs/pdf.js/${pdfjs.version}/pdf.worker.min.js`;
```

**Pros**: No build configuration needed
**Cons**: Requires internet connection, external dependency

#### Option 2: Local Worker File

1. Copy worker file to public directory:

```bash
cp node_modules/pdfjs-dist/build/pdf.worker.min.js public/pdf.worker.min.js
```

2. Update worker path:

```typescript
pdfjs.GlobalWorkerOptions.workerSrc = "/pdf.worker.min.js";
```

**Pros**: No external dependencies, works offline
**Cons**: Requires manual copy, needs updating when PDF.js version changes

#### Option 3: Webpack/Next.js Configuration

Add to `next.config.ts`:

```typescript
webpack: (config) => {
  config.resolve.alias.canvas = false;
  config.resolve.alias.encoding = false;
  return config;
},
```

## Troubleshooting

### Common Issues

#### Issue: Worker fails to load

**Error**: `Error: Setting up fake worker failed`

**Solution**:

- Check worker path is correct
- Ensure worker file is accessible
- Try CDN worker path as fallback

#### Issue: Canvas is blank

**Error**: PDF loads but canvas doesn't render

**Solution**:

- Check canvas ref is attached
- Verify viewport scale calculation
- Check browser console for WebGL errors

#### Issue: PDF.js version mismatch

**Error**: `Incompatible worker version`

**Solution**:

- Update pdfjs-dist package
- Update worker file if using local copy
- Clear Next.js cache: `pnpm clean:next`

#### Issue: Memory leaks with multiple PDFs

**Solution**:

- Ensure PDF documents are destroyed on unmount
- Check cleanup in useEffect return function
- Consider lazy loading PDFs

### Debugging Tips

1. **Enable PDF.js logging**:

```typescript
import { GlobalWorkerOptions } from "pdfjs-dist";
GlobalWorkerOptions.verbosity = 5; // Maximum verbosity
```

2. **Check network requests**:

- Open browser DevTools Network tab
- Look for PDF file requests
- Verify response content-type and status

3. **Inspect canvas rendering**:

- Check canvas element dimensions
- Verify canvas context is 2d
- Look for canvas errors in console
