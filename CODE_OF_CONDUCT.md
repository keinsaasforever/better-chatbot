# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, and keep criticism about the work, not
the person. Harassment, insults and discrimination are not tolerated in
issues, pull requests, discussions or Discord.

Report unacceptable behaviour to **support@keinsaas.com**. Reports are handled
confidentially.
