# Solar system textures

Planet, Sun, ring and Milky Way textures are derived from the
[Solar System Scope](https://www.solarsystemscope.com/textures/) texture
library, © Solar System Scope, licensed under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). They are based on
NASA imagery and elevation data.

Changes: resized to 1024×512, recompressed, bump maps computed from the normal
maps, Venus recoloured to its cloud deck, Earth cloud/roughness maps and the
Saturn ring strip extracted. Build script: `scripts/cockpit/build-solar-system-textures.py`.

Scene code adapted from [bobbyroe/solar-system](https://github.com/bobbyroe/solar-system)
(MIT, © 2024 Bobby Roe).
