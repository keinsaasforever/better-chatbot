# keinsaas Navigator – Community Edition (web app)

The Next.js app of [keinsaas Navigator – Community Edition](https://github.com/keinsaasforever/better-chatbot), formerly better-chatbot: an open-source AI chat and agent workspace you host yourself. Agents, projects with retrieval on pgvector, MCP servers, workflows and voice; any model through the Vercel AI Gateway, local models, or EU-hosted models with zero data retention.
